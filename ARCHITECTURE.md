## Key Design Decisions

1. **Local-First**: All agent execution happens locally by default
2. **YAML Config**: Human-readable, version-controllable configuration
3. **Connector Pattern**: Pluggable integrations with common interface
4. **CLI Primary**: All functionality accessible via CLI, web is enhancement
5. **No Forced Cloud**: Cloud sync is opt-in, never required
